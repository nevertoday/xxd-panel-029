# XXD Panel 029｜横向色域蜡粉笔手绘生产提示词

只处理当前任务明确提供的这一张源照片。先锁定主体或不可拆分关系、核心比例、轮廓走势、姿态、方向、动作、功能、关系距离与颜色性格，至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的横向色域、蜡粉笔节奏、配色、文字和构图。

## 一个横向低饱和纸张色域

在米白色粗纤维手工纸上设置一块横向延展的低饱和纸张色域。它的色相、冷暖、明度与情绪必须从当前照片的综合色彩和氛围中提炼并重新调和；不固定为粉、蓝、绿、棕或米色，也不能沿用上一张照片的颜色。

色域只承担主体与空间的关系，不成为风景或装饰。根据主体重心、朝向、动作和轮廓走势决定色域高度、垂直位置、主体尺度、偏置、裁切以及是否跨越色块上缘或下缘。横向色域、主体体量、正负形、上下留白必须形成一个有意的比例系统，不机械居中。

只使用这一块主要色域。禁止多色面板、边框、图案、贴纸、胶带、图章、散落图标、重复花纹和廉价手账装饰。

## 浅色哑光蜡粉笔主体

把主体简化为浅色、哑光的蜡粉笔体块和笔触。去除繁杂细节，保留核心比例、轮廓走势、姿态、方向、动作、功能和关系，让人一眼联想到原物。

笔触松弛、随性、不规整、略带断裂与粗糙摩擦感；覆盖可有轻微不均，边缘可局部断开、重触、擦扁或露出纸纤维，但关键轮廓必须可读。不能变成机械闭合描边、光滑数字插画、写实塑造或儿童卡通。

保留双层纸张的克制深度：横向色域像一层低饱和纸面落在粗纤维米白底纸上，只出现细微边缘差和触感，不做复杂剪贴。加入轻微做旧、Risograph 颗粒和极小套印偏差，但整体保持干净、高级、安静。

禁止丙烯色块、油亮蜡笔、彩铅排线、水彩晕染、水墨、厚涂、真实阴影、复杂光影、3D、光泽矢量和脏污滤镜。

## 源图颜色与留白

色域是画面的主要颜色事件。对源图综合色彩进行降饱和、统一综合色温与柔化，但保留它独特的冷暖关系和情绪性格。主体以浅色粉蜡为主，只保留识别所需的少量源图明暗变化。

米白手工纸和上下留白必须清楚可见。不同设备与画幅要重新安排色域比例、主体尺度、边界跨越、留白和文字安全区，不得裁切另一张成果。

## 松弛手写文字

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留；无文字时不生成任何字母、字符、数字、手写痕迹或伪文字。

自动文案从照片可见或有依据的情绪、动作、状态、关系或隐喻中提炼一句简短短句，只在真正有用时增加零至两个微型元素。地点、日期、编号和出处必须由用户提供或可靠确认，绝不虚构。

文字以目标文字系统中自然、柔软、潦草但可读、略带不完美的手写方式呈现，可沿色域边缘、主体走势或留白区域排列，也可与轮廓轻微穿插、错位或跨界。文字像手绘作品的一部分，禁止正式排版标题、粗体口号、商业手写字体、巨大字、发光字与伪外语。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计与壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果，不绘制系统 UI 或设备模型。连贯壁纸共同参考原照片与同一张已批准定调图，绝不串联衍生图。

硬性验收：至少三个源图线索与主要动作或关系；一块源图衍生的横向低饱和纸张色域；色域高度、主体尺度／偏置／裁切／跨界和上下留白形成有意比例；浅色哑光蜡粉笔主体保持核心比例与走势；笔触松弛、断裂、摩擦并抓住粗纤维；双层纸面、轻微做旧、Risograph 颗粒与微小套印偏差克制可信；文字自然手写并沿色域、主体或留白融入；无固定配色、儿童卡通、廉价手账、丙烯色块、复杂装饰、真实塑造、塑料 3D、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
