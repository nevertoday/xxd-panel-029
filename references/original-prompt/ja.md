# XXD Panel 029 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、独立系出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または環境背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**被写体、輪郭、姿勢、物語上の関係性**を抽出し、ゆったりとした素朴なワックスパステルの手描き画像として再構成します。生成り色の粗い繊維を持つ手漉き紙を下地とし、画面内に横方向へ広がる低彩度の紙の色面を設けます。その色は上の写真の総合的な色彩と感情から自然に抽出して再調合し、色相を固定しません。被写体は明るい色のマットなワックスパステルで概括的に描き、複雑なディテールを取り除き、最も核心的な比率、流れ、識別特徴だけを残します。線は自由で、不規則で、やや途切れ、粗い摩擦感を帯びさせ、上の元の対象を一目で連想できると同時に、独立した手描き表現を持たせます。

構図では、**横方向の色面、被写体の重心、上下の余白の間にある比率関係**を強調します。被写体は元画像の姿勢に応じて自然に偏らせ、裁ち落とし、または色面の境界をまたがせることができ、機械的に中央へ配置する必要はありません。スケール、方向、正負の形、余白を利用して静かな視覚的リズムを構築します。色面は被写体と空間の関係だけを担い、余計な装飾は加えません。二層の紙、わずかな経年加工、Risographの粒子、リアルな繊維の質感を残し、複雑な影、写実的な造形、デジタルな滑らかさは避けます。

写真の**感情、動作、状態、または隠喩**から短い一文を抽出し、柔らかく、走り書きのようで、わずかに不完全な手書きで画面に溶け込ませます。文字は色面の縁、被写体の流れ、または余白領域に沿って自然に配置できるほか、輪郭とわずかに交差させたり、ずらしたり、境界をまたがせたりすることもでき、後から追加したタイトルではなく、手描き作品の一部のように見せます。

全体として、**静かで、ゆったりとし、優しく、レトロで、文芸的かつ抑制された**紙上のエディトリアルビジュアルを表現し、手仕事の温かみとモダンな構図感を兼ね備えます。被写体が人物、動物、植物、建築、器物、乗り物、自然景観のいずれであっても、リアルな写真とミニマルな手描きの間に明確で巧みな視覚的呼応を保ち、カートゥーン感、安っぽいスクラップブック感、複雑な装飾、固定配色、テンプレート感は避けます。
